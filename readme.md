# penjelasan web
Website portofolio yang kamu buat menampilkan identitas diri dengan nuansa visual lembut. Bagian awal halaman menonjolkan foto profil beserta perkenalan singkat untuk memberi kesan personal. Lanjut ke segmen About Me, pengunjung bisa membaca deskripsi singkat mengenai latar belakangmu. Di bawahnya terdapat Portofolio yang menampilkan hasil karya dalam bentuk gambar sehingga menunjukkan kemampuan dan pengalaman. Terakhir, bagian Contact menyediakan tautan ke media sosial dengan desain tombol interaktif berwarna pink yang berubah saat diklik, sehingga memudahkan pengunjung untuk langsung terhubung. Struktur ini sederhana namun efektif, membuat navigasi jelas dan tampilan keseluruhan terasa modern serta ramah pengguna.
